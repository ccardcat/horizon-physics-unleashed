PHYSICS UNLEASHED — Windows 10/11, x64

1. Распакуйте весь скачанный ZIP в отдельную папку.
2. Дважды нажмите Start-Physics-Unleashed.cmd.
3. В новом творческом мире с включёнными командами:
   /physics spawn 8.5 80 8.5
   /physics gravity 0 9.81 0
   /physics clear

Выберите загруженное место над землёй. Для повторяемой демонстрации в этом
отдельном тестовом мире можно поставить площадку на y=70 и освободить место:
   /tp @s 12 77 12
   /fill 4 71 4 12 96 12 minecraft:air
   /fill 4 70 4 12 70 12 minecraft:stone
   /physics spawn 8.5 80 8.5

Сохранения этой демонстрации находятся в demo-data рядом с программой.
Обычные сохранения Horizon не изменяются программой запуска.

РЕСУРСЫ MINECRAFT
В ZIP нет файлов Minecraft. Нужна ваша копия Java Edition и подготовленные
ресурсы Horizon версии, указанной в research-lock.json (сейчас 26.3).
Если обычный Horizon уже запускался через Horizon Launcher, программа
запуска автоматически ищет его подготовленные ресурсы в
%APPDATA%\horizon-launcher\versions\...\.local\horizon-client\26.3.
Также поддерживаются папки resources или .local\horizon-client\26.3 рядом с EXE.
Если найти ресурсы автоматически не удалось, откроется выбор папки — выберите
ту, в которой есть файл horizon-resources.json.

Если Horizon ещё не установлен: установите обычный Horizon Launcher с
https://playhorizon.dev и завершите подготовку ресурсов из вашей копии
Minecraft 26.3. После первого успешного запуска Horizon снова откройте
Start-Physics-Unleashed.cmd. Программа не скачивает игровые файлы сама.

В комплекте: horizon-client.exe (игра), horizon-ctl.exe (автоматизация),
COMMIT.txt (исходный коммит), SHA256SUMS.txt (контрольные суммы).
Физика включена при сборке. Звук и контроллеры включены. Моды на Java не запускаются.
Это экспериментальная сборка без цифровой подписи. Графическая демонстрация
требует реальной игровой проверки с вашими ресурсами и видеодрайвером.
